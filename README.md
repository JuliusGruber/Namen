# Namen - Dynamic Name Printer

A fun web app that prints your name repeatedly with crazy, randomized styling effects.

## What it does

Enter your name and watch it appear over and over again in a vertical list - but each time with completely different fonts, colors, sizes, animations, and visual effects.

## Tech Stack

- Vanilla HTML/CSS/JavaScript
- No frameworks, no dependencies

## How to Use

1. Type your name in the input field
2. Press Enter or click "Print"
3. Watch your name appear with random styling variations
4. Click "Reset" to clear and start over

## Features

- Dynamic font styles and sizes
- Random colors and gradients
- Text shadows and effects
- Entrance animations (fade, bounce, slide, rotate, etc.)
- Vertical scrolling list
